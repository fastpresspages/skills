Agent skills that ship, scan and triage.

The playbook behind every FastPress Labs repo, packaged as three installable skills: a release playbook, a weekly field-scan routine, and an honest inbox triage. Markdown plus tiny zero-dependency scripts — nothing you can't read in one sitting.

npx skills add fastpresspages/skills

Works with skills.sh-compatible agents (Claude Code, OpenCode…). Frontmatter is plain YAML.

01 fastpress-release

Ship a new project end-to-end: name research (npm + GitHub), the standard kit files, the LaunchGrade audit loop, GitHub Pages, release tagging and cross-linking. Inputs, guardrails and ship order included.

02 fastpress-teardown

Weekly public field scans: pick fresh HN launches with the read-only picker, grade them fully (not --fast), publish strengths-first with a removal-on-request policy, re-scan with --compare.

03 fastpress-support

One inbox, five buckets: audit, deal, collab, support, spam. Classify with the stdin script, act with the smallest honest unit first, escalate deals through the written deal ladder only.

How it stays safe

  • Scripts read, never act. The picker only lists HN Show items; the triage script only reads stdin. No auto-posting, no auto-sending, no form submissions.
  • Rules over vibes. Skills include the refusal rules: no fake metrics, no fake scarcity, no uninvited outreach, corrections within a day.
  • Zero dependencies. Node ≥ 18.17 standard library only — you can read `hn-top.mjs` and `triage.mjs` in one sitting.
  • CI-guarded. A self-check verifies frontmatter, script wiring and README consistency on every push.

FAQ

How do I install the skills?

Run npx skills add fastpresspages/skills. Each skill is a folder with a SKILL.md; installers read the frontmatter.

What can the scripts actually do?

Read only. The HN picker lists fresh Show HN launches; the triage script classifies message text on stdin. Nothing posts, sends or submits automatically.

Are the skills free?

Yes. Apache-2.0, zero runtime dependencies, no telemetry, no accounts.

Who wrote them?

FastPress Labs (Meet Shah), with agents drafting and humans reviewing before publish. The same kit shipped every FastPress Labs repo.
